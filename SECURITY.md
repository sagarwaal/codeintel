# Security Policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in public issues with sensitive details.

Open a private security advisory through GitHub's Security tab if private vulnerability reporting is enabled for this repository. If it is not enabled, contact the repository maintainer privately using the contact information listed on the GitHub profile.

## Scope

Project Intelligence analyzes repositories and writes local documentation. Its output may reveal architecture, security assumptions, internal paths, or other sensitive context. Review generated files before sharing them.

Never place credentials, access tokens, private keys, or sensitive production data in the generated knowledge base.
